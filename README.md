# Cybersecurity Course 2026 – Exercises

Selles repos asuvad **Cybersecurity Course 2026** praktiliste harjutuste näidislahendused.

Repo ei sisalda kogu kursuse õppematerjali. Siin on peamiselt kood ja näited, mida kasutame tunnis praktiliste ülesannete tegemisel.

Harjutused on jaotatud kursuse peatükkide järgi ning ühe teema erinevad kaustad näitavad samm-sammult, kuidas lahendus areneb.
